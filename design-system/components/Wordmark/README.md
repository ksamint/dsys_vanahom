# Wordmark

The VANAHOM wordmark as SVG artwork; place it, never retypeset it.

**Consumer provides:** the variant and a width (height follows the 1000 × 155.81 viewBox, ratio 6.42 : 1).

| Variant | File | Use on |
| --- | --- | --- |
| Red (primary) | `assets/Logos/vanahom-wordmark-red.svg` | paper, mist: covers, page headers, sign-offs |
| White | `assets/Logos/vanahom-wordmark-white.svg` | hongtu-red fields, dark photos |
| Grey | `assets/Logos/vanahom-wordmark-grey.svg` | hongtu-red banners (BioBanner) and quiet contexts; 1.41:1 on paper, so never on white |
| Ink | `assets/Logos/vanahom-wordmark-ink.svg` | single-colour print, fax, embossing |
| Square red / grey | `assets/Logos/vanahom-square-*.svg` | avatars, app and social tiles |

- Clear space: at least one V-height (the cap height) on every side.
- Never recolour outside the palette, add gradients or shadows, stretch, rotate, outline or crowd it.
- In running text write 凡纳弘途 first, VANAHOM as the labelled alternate.
