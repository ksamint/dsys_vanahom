# SectionTitle

The page header of every corporate page: brand or chapter word in hongtu-red, a red bar separator, the topic in ink, a 96px red rule under it, the red wordmark at the right.

**Consumer provides:** the lead word (`凡纳弘途`, `服务内容`, `团队履历`, `足迹`, `展望`, `携手共赢`), the topic, and whether the wordmark shows (default yes).

- Set the text in `h2`; the lead word is the only red text on the page header.
- Keep it on paper. One per page or slide.
- Do: short topics (≤ 14 characters). Don't: add an English subtitle here; put it in a `lead` below.
