# Eyebrow

A 12px uppercase label with a short hongtu-red rule, placed above a heading to name the section.

**Consumer provides:** one short label, bilingual allowed (`Our belief · 我们的信念`).

- The only uppercase style in the system. Cangling grey is 2.27:1 on paper, so the eyebrow is decoration: the heading below must carry the meaning.
- One per section; never inside body text or tables.
