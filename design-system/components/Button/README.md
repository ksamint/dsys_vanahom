# Button

Actions. Quiet outline by default; **primary** (hongtu-red) once per view for the one thing the page asks; **text** for inline links.

**Consumer provides:** a verb-first label (`预约咨询`, `下载品牌手册`), the variant, and `disabled` when unavailable.

- Corners `radius-sm` (2px), never rounder. 44px minimum height.
- Focus ring: 2px solid `hongtu-red-deep`, 2px offset (9.0:1 on paper).
- Hover deepens red to `hongtu-red-deep` over `motion-base` (320ms ease-out).
- Intentional addition: the deck has no buttons; this follows the guideline's “red for calls to action”.
